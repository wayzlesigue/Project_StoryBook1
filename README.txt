WEBTOON STORY LIBRARY

How to run:
1. Extract the ZIP folder.
2. Open the Manga_Storybook_InkVerse folder in VS Code.
3. Open index.html with Live Server, or double-click index.html to open it in a browser.

Project structure:
- index.html: homepage and manga library
- style.css: website design
- script.js: search, genre filter, and detail popups
- images/: local JPG cover images linked to matching titles on the library and story pages; original SVG covers are also included
- stories/: one separate HTML page for each title

The library uses local JPG cover images matched to each title. Story chapters are original unofficial fan-made fiction.
